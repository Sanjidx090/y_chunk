CHOOSING YOUR CHUNK MODE
═══════════════════════════════════════════════════════════════════════

Edit chunk_downloader.py and set CHUNK_MODE:

┌──────────────────────────────────────────────────────────────────┐
│ MODE: "full"                                                      │
├──────────────────────────────────────────────────────────────────┤
│ What: Entire transcript as 1 file per video                      │
│ When: General analysis, reading, simple processing               │
│ Output: 275 files (1 per video)                                  │
│ Config: CHUNK_MODE = "full"                                      │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ MODE: "fixed" ⭐ RECOMMENDED FOR MOST USE CASES                  │
├──────────────────────────────────────────────────────────────────┤
│ What: Split into equal N-second chunks                           │
│ When: Training models, batch processing, uniform segments        │
│ Output: ~50-100 chunks per video (depends on duration)           │
│ Config:                                                           │
│   CHUNK_MODE = "fixed"                                           │
│   CHUNK_DURATION = 30  # 30 seconds per chunk                    │
│                                                                   │
│ Recommendations:                                                  │
│ • 10-15s: Short audio clips (speech recognition)                 │
│ • 20-30s: Standard training segments                             │
│ • 45-60s: Longer context windows                                 │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ MODE: "sentences"                                                 │
├──────────────────────────────────────────────────────────────────┤
│ What: Each subtitle segment becomes a chunk                      │
│ When: Sentence-level analysis, fine-grained alignment            │
│ Output: ~200-500 chunks per video                                │
│ Config: CHUNK_MODE = "sentences"                                 │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ MODE: "custom"                                                    │
├──────────────────────────────────────────────────────────────────┤
│ What: Use your own time ranges (e.g., from VAD)                  │
│ When: You have specific segments to extract                      │
│ Output: Depends on your ranges                                   │
│ Config:                                                           │
│   CHUNK_MODE = "custom"                                          │
│   CUSTOM_CHUNKS = {                                              │
│     "video_id_1": [(0, 10), (15, 30)],                          │
│     "video_id_2": [(5, 20), (25, 40)]                           │
│   }                                                               │
└──────────────────────────────────────────────────────────────────┘

USING THE TRANSCRIPTS
═══════════════════════════════════════════════════════════════════════

Python Example - Load a chunk:
```python
import json

with open('bangla_transcripts_merged/nAkV9oOZaz0/chunk_0000.json') as f:
    chunk = json.load(f)

print(f"Text: {chunk['text']}")
print(f"Time: {chunk['start']}s - {chunk['end']}s")
```

Get all text for training:
```bash
cat bangla_transcripts_merged/*/chunk_*.txt > all_bangla_training.txt
```

Count total chunks:
```bash
find bangla_transcripts_merged -name "chunk_*.json" | wc -l
```

Load all chunks for ML:
```python
import json
from pathlib import Path

transcripts = []
for video_dir in Path('bangla_transcripts_merged').iterdir():
    if video_dir.is_dir():
        for chunk_file in sorted(video_dir.glob('chunk_*.json')):
            with open(chunk_file) as f:
                transcripts.append(json.load(f))

print(f"Loaded {len(transcripts)} chunks")
```

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: "Rate limited" after 20-30 videos
Solution: Normal! The script saves progress. Wait 1-2 hours and re-run
         with RESUME=True (default). It continues where it stopped.

Problem: Some videos fail to download
Solution: Check transcript_download_summary.csv for success/fail status.
         Failed videos can be retried individually later.

Problem: Running out of storage
Solution: Process in smaller batches. Set BATCH_SIZE = 25 instead of 50.

Problem: Takes too long
Solution: Use "full" mode instead of "sentences" mode. Fewer files = faster.
